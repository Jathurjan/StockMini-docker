# StockMini – Inventory Management System

StockMini is a simple Inventory Management System developed using Laravel 13, PHP, and MySQL.

This project is built as a practical learning project to understand Docker containerization and DevOps fundamentals.

## Tech Stack

- Laravel 13
- PHP 8.4
- MySQL 8.4
- HTML
- CSS
- Blade Templates
- Docker

## Features

- Product Management (CRUD)
- Inventory Dashboard
- Stock Quantity Tracking
- Low Stock Alerts
- Out of Stock Detection
- Product Search
- Product Category Management

## DevOps Learning Objectives

- Dockerfile creation
- Docker Image Building
- Docker Container Management
- Docker Compose
- Docker Volumes
- Docker Networks
- Database Containerization
- Git and GitHub Integration

## Project Purpose

This project is developed to gain hands-on experience in Laravel application development, Docker containerization, and fundamental DevOps practices.
